# Systementor Zoo

## Om projektet

Projektet är en responsiv webbplats för Systementor Zoo. Webbplatsen är skapad med HTML och CSS och är anpassad för mobil, surfplatta och desktop. På webbplatsen kan besökaren läsa om djuren, se aktiviteter, prenumerera på nyhetsbrevet och hitta information inför ett besök.

## Installation

1. Kopiera repositoryts URL.
2. Öppna Visual Studio Code och öppna terminalen.
3. Navigera i terminalen till mappen där du vill spara projektet.
4. Klona repositoryt till din dator:
   ```bash
   git clone https://github.com/annabyte95/systementor-zoo.git
   ```
5. Öppna den klonade projektmappen i Visual Studio Code.
6. Kontrollera att tillägget Live Server är installerat.
7. Öppna `index.html` med Live Server.

## Kända problem

Menyknappen i mobilversionen har ännu ingen funktionalitet. Navigeringen kan utvecklas med JavaScript i framtiden.
